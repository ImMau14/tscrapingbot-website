## 🚀 Despliegue

### ⚙️ Requisitos

Debe de tener NodeJS instalado, preferiblemente la última versión.

1. Clona y entra en el repositorio:

```bash
git clone https://github.com/ImMau14/tscrapingbot-website
cd tscrapingbot-website
```

2. Instala las dependencias. (sugiero usar pnpm):

```bash
pnpm install
```

3. Arranca el proyecto:

```bash
pnpm run dev # O pnpm run build, si quieres generar los archivos estáticos
```
