## 🚀 Deployment

### ⚙️ Requirements

You need to have NodeJS installed, preferably the latest version.

1. Clone and enter the repository:

```bash
git clone https://github.com/ImMau14/tscrapingbot-website
cd tscrapingbot-website
```

2. Install dependencies (I suggest using pnpm):

```bash
pnpm install
```

3. Start the project:

```bash
pnpm run dev # Or pnpm run build if you want to generate static files
```
